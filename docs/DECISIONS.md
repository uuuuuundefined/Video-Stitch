## 已取代或撤回的旧建议

- D-05：旧“500 项强制二次确认”未获独立确认，不作为批准规则。本次采用页面数量/空间摘要及资源预检，不设固定数量上限。
- D-08：旧“1GB 预览缓存、20MB/7天日志”作废，由 D-12、D-21 取代。
- 不采用 1080p 上限、三个页面、预览功能、独立应用任务数据库、软件内清理/卸载入口，以及保留 HEVC 输出的旧建议。
- 用户明确要求不改原型保存目录的现有逻辑；本次不更换初始路径文字，不改为另一套导出前路径展示。

## 历史与实施边界

- 2026-10-19 / D-23：用户确认 Windows 专项审查后的修复。新私有运行目录排除为导出/恢复位置，启动及卸载只清理有正确归属标记的新目录；旧目录无法排除任务数据混入，不自动递归删除。此修复不授权删除任何既有导出成果。

- 2026-10-19 / D-02：用户确认取消“音轨超出画面区间”校验，以画面时长优先拼接，超出的声音直接裁掉。取代此前“真实声音明显长于画面时阻断、不自动裁音”的规则。

- 2026-10-19 / D-25：用户最终选择“仅本次运行记住”，撤回重启后保留目录的方案；不在安装目录、用户目录或系统目录新增目录记忆文件。
