# Video Stitch v0.1.1

本次更新调整工作台外观，默认使用明亮的日间模式。

- 新增日间配色，适配卡片、按钮、状态栏和弹窗。
- 右上角新增 `[ 日间 / 夜间 ]` 切换，保留原有终端字体及布局。
- 加粗 `01 / INPUT`、`02 / QUEUE`、`03 / EXPORT` 章节标题。
- 视频拼接、导出、恢复及卸载数据保留规则保持不变。

下载附件：

- `*-setup.exe`：Windows 10 22H2+ / Windows 11 x64 安装包。
- `*.dmg`：macOS 13+ Apple Silicon 安装映像，打开后将应用拖到“应用程序”。
- `SHA256SUMS.txt`：两份安装包的 SHA-256 校验和。

安装包尚未正式签名；macOS 尚未公证，系统可能提示无法验证开发者。请仅在确认下载来源可信后，按系统提示在“隐私与安全性”中允许打开。组织策略可能禁止未签名应用。

Windows 基础媒体组件提供 libx264 软件编码；NVENC/QSV/AMF 硬件编码、缺少 WebView2 的离线设备、macOS 13 干净设备及完整生产设备矩阵仍待验收。已完成的 CI 核心测试、真实媒体测试和 Windows 安装/卸载检查不替代上述验证。详细范围见仓库 `docs/VALIDATION.md`。

安装包内附匹配的 FFmpeg/x264 源码、许可证及构建资料；第三方许可保持原样，应用本身尚未指定开源许可证。
