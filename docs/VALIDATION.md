## 媒体组件与打包

Mac FFmpeg/ffprobe 由 FFmpeg 8.1.2 与 x264 精确提交 `b35605ace3ddf7c1a5d67a2eb553f034aef41d55` 构建。FFmpeg 与 x264 都明确设置 `MACOSX_DEPLOYMENT_TARGET=13.0`；`otool` 校验只依赖 `/usr/lib` 和 `/System/Library`。不依赖 Homebrew、外部 Node/Rust/Python 或网络，组件随 `.app` 一并安装、移除。最低版本加载命令为 13.0；仍需在 macOS 13 真机执行兼容性测试。

包内 `resources/media` 包含匹配源码、GPL 许可、构建配置、配方及 SHA-256。`check-release.mjs` 拒绝开发组件、哈希不符或 Mac 非系统动态库依赖。应用本身尚未选择公开分发许可证，发布前需确认；第三方源码许可保持原样。

## 存储与清理边界

业务写入仅有输出视频、唯一进行中视频和 `unfinished-tasks.<UUID>.json` / 同类原子更新记录。恢复记录不保存探测结果、错误历史、逐帧进度、性能、设置库或视频副本。拼接清单通过 stdin 传递，试编码使用空设备；不生成预览、缩略图或业务日志。

Mac 使用 nonPersistent WebView；需继续盘点 WebKit 系统托管数据和异常退出后的实际目录差异。可能的应用自有路径为：

```text
~/Library/Application Support/com.videostitch.desktop
~/Library/Caches/com.videostitch.desktop
~/Library/WebKit/com.videostitch.desktop
~/Library/Saved Application State/com.videostitch.desktop.savedState
~/Library/Preferences/com.videostitch.desktop.plist
~/Library/HTTPStorages/com.videostitch.desktop
```

本轮正常退出实测：前四个目录及 HTTPStorages 不存在；系统原生文件选择器曾生成 854 字节的 Preferences plist，键为最近根目录、GoTo 窗口位置和选择器尺寸。选择器返回/退出时直接清除 NSUserDefaults 后，系统仍可能在收尾时再次写入最近根目录。实现改为：启动先清旧偏好，退出由同一可执行文件的受限清理模式等待主进程结束后清固定偏好域及文件。清理进程最多等主进程 20 秒，正常清理约 1.2 秒后结束，无常驻服务、无清理清单、无输出目录访问。不把 nonPersistent 当作所有系统组件零落盘的证明。

最终优化包实测：关闭 Vite 开发服务后可独立启动；打开并取消原生选择器、正常关闭应用后，上述六处固定自有路径均不存在，四个导出文件仍保留。该证据限于当前机器及已操作流程，不替代全生命周期磁盘差异审计。

`scripts/uninstall-macos.sh` 在应用退出后只清理以上固定归属路径及偏好域，不扫描、读取或清理任何导出目录。它也随包提供。Windows 新版使用带归属标记的 `%LOCALAPPDATA%/com.videostitch.desktop/Runtime-v2/WebView`；启动、退出及 NSIS 卸载只处理已确认归属的新目录，输出及恢复入口排除该运行区域。旧版 `WebView` 目录不自动递归删除，以保护其中可能存在的任务数据；上级目录只允许删除空目录。Windows runner 的正常退出、启动立即关闭和卸载清理已有通过证据；真实设备矩阵仍待验收。

## 未完成的生产验收

以下未验证项不得标为通过：

1. 真实 Windows 10/11 设备矩阵、缺少 WebView2 的离线干净设备、NVENC/QSV/AMF、原生选择器和完整业务界面操作，以及签名。Windows runner 已验证的构建和安装/卸载范围见上文。
2. Mac 正式签名、公证、macOS 13 干净设备安装，以及安装前后、正常/异常退出和卸载的完整磁盘差异检查。
3. 代表性人物/字幕/高速运动、4K、VFR、旋转/SAR、色彩与编码器画质阈值；启动短样本不能替代这些基线。
4. 实际万项任务界面与性能预算、峰值资源/吞吐三轮中位数；目前采用分页和有界调度，不据此声称预算已通过。
5. 磁盘满、拔盘、休眠唤醒、父进程强制终止的子进程生命周期，以及全部原子落盘点的系统级故障注入。已覆盖的优雅停止/模拟提交窗口崩溃不等于这类全覆盖。
6. Mac 独立托管 WebView 进程的完整归属采样；当前只统计可识别进程树，内存使用平台 footprint/私有提交口径。GPU 编码引擎占用尚无可靠采样，按 PRD 显示暂不可用。
